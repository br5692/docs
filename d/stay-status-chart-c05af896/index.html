Target Account = a checkbox, not a status (agreed 11/19). Leadership ticks it on the accounts reps should break into this quarter (owner Sam for SMB / Mid-Market, Ryley for Enterprise). It sits on top of any status, so a Target can be Unworked, Working or In Opportunity. At quarter end, each Target is reviewed: keep, or untick.
